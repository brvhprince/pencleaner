# Illustrations

`vendor/` holds the "Empty States" animated illustration pack from UI8, used under the
project owner's licence. The pack's own licence terms still apply to these files: being
in this repository does not grant others a licence to reuse them outside PenCleaner.

`Illustration.svelte` loads whatever SVGs are present and falls back to a neutral
placeholder, so swapping in your own artwork only means dropping SVGs with the same
names into `vendor/`.
